# Recursos visuales

- `land.geojson`: Natural Earth, capa `ne_110m_land`, dominio público.
  Fuente: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson
  Condiciones: https://www.naturalearthdata.com/about/terms-of-use/
  Descarga: 30 de octubre de 2026. Se distribuye localmente; el juego no consulta mapas externos.
- Ilustraciones de monumentos: SVG originales y estilizados escritos para este proyecto en
  `presentation/components/game/landmark-art.tsx`. No son planos arquitectónicos.
- Iconos: Lucide, licencia ISC, distribuida por el paquete `lucide-react`.
- Tipografías: familias del sistema; no se descargan fuentes de terceros.
